Verified identities:
  exact safe cube terms      = 2^n
  exact safe cube literals   = n * 2^n
  MTBDD internal nodes       = sum_{k=0}^{n-1} min(q, k+1)
  MTBDD reachable terminals  = min(q, n+1)
  additive EV diagram nodes  = n + 1
  additive EV edge labels    = 2n values, each ceil(log2 q) bits

Interpretation:
- Edge values factor cyclic semantic state away from physical nodes.
- The factorisation remains honest only when label bits and arithmetic are charged.
- Fully sensitive modular outputs defeat every monochromatic subcube cover.
